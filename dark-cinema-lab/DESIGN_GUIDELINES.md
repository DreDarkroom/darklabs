# Dark Cinema Lab - Design Guidelines

## 1. Colour Palette
- **Primary Accent Colour**: `#690000` (Dre Darkroom Red)
- **Background Colour**: `bg-neutral-950`

## 2. Typography and Spelling
- **Spelling standard**: Strictly use UK English spelling conventions across all copy, code, and documentation (e.g., "analogue", "colour", "visualiser").

## 3. General Rules
- Maintain high-contrast, moody aesthetic in line with darkroom themes.
- All subsequent code must strictly adhere to these guidelines.

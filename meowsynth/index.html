MeowSynth_

a browser synth made entirely of human "meow" impressions

(browsers block audio until you interact — one click and it's live)

0

chromatic meow keyboard — keys A W S E D F T G Y H U J K O L P ; '

mood pads — keys 1–7

how to use this thing
  • Row A → ' is a chromatic scale — every key is a semitone up from the last, all pitch-shifted from one recorded meow.
  • Z / X (or the − / + buttons) shift the whole keyboard up or down an octave.
  • Number keys 1–7 fire seven different meow one-shots — a chirp, a yowl, a grumble, a shriek, and friends.
  • Filter tames the brightness, Reverb adds space, Release controls how long each meow rings out, Volume is volume.
  • Click the keys/pads on screen too — works on touchscreens.

part of Dre Darklabs — built from two human vocal recordings, sliced into samples and run through the Web Audio API. no libraries, no build step, one page. source on GitHub.

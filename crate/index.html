Crate Capture

Find music you are allowed to use, prove it, and hand it over cleanly. Everything you type stays on this device.

The short version

  1. Find it in a place that is built for open music (the Sources tab).
  2. Check the licence in three places: the page, the file, and the uploader. Six checks, below.
  3. Download the original, from the official button. Never rip a stream.
  4. Fingerprint and log it in My finds: where, who, which licence, the evidence, the SHA-256.
  5. Listen and rate it: Love, Keep, Maybe, Drop. Only keep what you are happy with.
  6. Prepare it (loudness, names, tags), then export the sheet and LICENSES.txt with it.

The rule that saves you: when in doubt, leave it out. A track you cannot prove is not a track you can submit.

1. What CC0 means, and what it does not

CC0 (say: see-see-zero) is a public domain dedication. The person who made the work gives up all their copyright, everywhere, so anyone can copy, change, sell and share it with no credit and no permission. See licence in the Word Lab.

It only waives copyright. It does not cover trademarks, a person's privacy or likeness (a recognisable voice, for example), or rights that other people hold in the work. So a CC0 label is a strong claim, not a guarantee. You are checking whether the claim is true.

Public domain by age is different: no one dedicated it, its copyright simply ended. That depends on the country, and a song and a recording of it can end on different dates. Old US recordings from before 1923 are public domain in the US, and 1925 recordings joined them on 1 January 2026. Other countries run different clocks.

One more thing to know: in some countries, performers and record makers hold rights (for example to be paid when a recording is broadcast) that cannot always be given up, even by a CC0 dedication. This is why the best evidence is the maker's own written statement, saved with the untouched original. If a track will be used somewhere that matters, ask the person you are sending it to what proof they need.

2. The six checks (every find, every time)
  1. The licence is on the page. Save the address and, if you can, a screenshot or a saved copy of the page. Pages change.
  2. The licence is in the download. Open the zip. Read any readme, text file or tags. If it says something stricter than the page, believe the stricter one.
  3. The uploader is the maker (or the piece is public domain by age). Read the profile. Does the account make this kind of music? Is there a pattern of uploads that look like other people's?
  4. No samples, covers or borrowed voices. Listen for a recognisable riff, vocal or drum break. Search a distinctive phrase. "Free" remixes of protected songs are not free.
  5. Both rights are covered. The recording and the composition. A CC0 recording of someone else's song is not enough.
  6. Nothing else restricts it. A site rule such as "not on its own", a brand name in the title, a person's name or voice.

A real example from this project's own sound work: a pack labelled CC0 on its page contained a text file saying CC BY 3.0. It was logged and credited as CC BY, and kept out of the CC0 set.

3. Searching wide and far (how to find more)
  • Start narrow, then widen. Search by mood and use ("slow dark ambient loop"), then by instrument, then by tempo, then by collection. Write down the searches that worked.
  • Follow creators, not just tracks. If one creator publishes everything as CC0, their whole page is a source. Kenney and the Open Goldberg Variations are examples.
  • Use a finder, then go to the original. Openverse searches several open sites at once. Always open the original page for the checks.
  • Use the filters. Freesound, OpenGameArt, Openverse, Free Music Archive, ccMixter and the Internet Archive can all limit results to CC0 or public domain. The Tools tab has the exact settings and commands.
  • Look at collections and tags, then check each item anyway. A tag is a hint, not proof.
  • Old music, new performance. Public domain scores (IMSLP, Mutopia) plus your own recording make music you can dedicate yourself.
  • Write your own. Nothing beats it: you know exactly where every sound came from.
  • Keep a "searched" list (the Notes field in each find, or your own file) so you do not repeat yourself.

The Sources tab lists 16 places with what to expect from each, and the list of things that look free but are not.

4. Downloading safely
  • Use the site's own download button or its official API or command-line tool. Do not record a stream or use a "downloader" site.
  • Keep the original file and the whole zip with its readme. Do not re-encode the original: make a copy to work on.
  • Make the original read-only, and keep it in a folder named after the source.
  • Check the file really is what the page said (length, format) and that it opens.
  • Compute its SHA-256 fingerprint straight away. Crate Capture does this for you in the browser (nothing is uploaded), or use the command in the Tools tab.
  • Large or many files: use the site's official tool (for example the Internet Archive's ia) rather than clicking one at a time, and be kind: do not hammer a small site.
5. Documenting: the provenance record

Provenance means the history of where something came from. For each find, write down:

  • Title, creator, the page address, and the day you checked.
  • Which licence, the licence address, and the evidence: exactly where you saw it ("licence box on the page; readme.txt line 3").
  • The six checks, ticked only when true.
  • The file name, size, and SHA-256 fingerprint.
  • Your rating and notes.

In My finds a track is marked Ready only when all of that is present. Export a provenance sheet (CSV), a LICENSES.txt and the whole log (JSON) to go with whatever you hand over. Keep a copy of the JSON somewhere safe: clearing the browser's data erases the log.

6. Listening, choosing, and being happy with it
  • Listen on speakers and on headphones, at a normal volume, all the way through.
  • Rate it in My finds: Love (I would be proud to submit it), Keep, Maybe, Drop.
  • Ask: does it have a clear start and end? Is it clean (no clipping, no hiss, no stray noise)? Does it loop if it should? Does it fit with the rest of what you are sending?
  • A short, honest set of tracks you love beats a long list you are unsure about.
7. Preparing files (loudness, names, tags)
  • Keep the original untouched. Prepare a copy.
  • Loudness: measure first, then adjust only if needed. Commands are in the Tools tab. Do not make things louder just to be louder: leave headroom (a true peak under about -1 dBTP).
  • Names: source_title_creator_licence in lower case, no spaces. Crate Capture suggests one.
  • Tags: write the licence and the source address into the file's metadata, so the information travels with the file.
  • Format: WAV or FLAC for delivery unless the receiver asks for something else. Do not turn an MP3 into a WAV and call it lossless.
8. Handing it over

A tidy pack is easy to trust:

my-cc0-pack/
  audio/                     the prepared files
  originals/                 optional: the untouched downloads
  LICENSES.txt               from Crate Capture
  provenance.csv             from Crate Capture
  README.txt                 who you are, what this is, the date

Read the receiver's own rules first (format, length, naming, what they want to know). If you do not know where you are sending it yet, build the pack anyway: it will be ready.

If it is your own music: say so plainly in the README ("I made every part of these tracks and dedicate them to the public domain under CC0 1.0"), name any collaborators and say they agreed, and remember CC0 cannot be undone.

9. If something turns out to be wrong

Mark it Rejected in your log and keep the note about why. If it was on a site, use that site's report option (Freesound has "Flag it" on each sound). If you already sent it, tell the person you sent it to straight away and offer to remove it. Everyone makes this mistake at some point; hiding it is the only real mistake.

    Using the tools together

    1. Crate Capture (this page) keeps the record, fingerprints a file, plays it for a first listen, and writes the sheet and LICENSES.txt. It never uploads anything.
    2. Earshot is the Darklabs audition tool with Love / Keep / Maybe / Drop tagging. At the moment it is a prototype that works on its own built-in tracks and does not load your own files yet: use the player in Crate Capture for now. Loading your files into Earshot is on its roadmap.
    3. DarkDesk can remember the work around this ("check the licence on three tracks", "send the pack by Friday") with reminders. It does not know about your finds; it is only a notebook.
    4. Word Lab explains the words (licence, public domain, sample, loop, BPM…).

    Everything below is an instruction for you to run yourself. This page does not run commands, download music or contact any site.

    Fingerprint a file

    The SHA-256 is a short code that changes if even one byte of the file changes. It proves the file you submit is the file you checked.

    Windows (PowerShell)
    Get-FileHash .\track.wav -Algorithm SHA256
    Mac or Linux
    shasum -a 256 track.wav

    Look inside a file (needs ffmpeg)

    Length, format
    ffprobe -v error -show_entries format=duration:stream=codec_name,sample_rate,channels -of default=nw=1 track.wav
    Measure loudness and peak (changes nothing)
    ffmpeg -hide_banner -i track.wav -af ebur128=peak=true -f null -

    Read the summary at the end: Integrated loudness (LUFS), Loudness range, True peak (dBTP).

    Make a normalised copy (the original stays as it is)
    ffmpeg -i track.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 track_norm.wav

    This one-pass version is fine for listening. For delivery, normalise by measuring first and applying a gain, and always listen to the result.

    Write the licence into the file's tags (FLAC)
    ffmpeg -i track.wav -c:a flac -metadata title="Title" -metadata artist="Creator" -metadata copyright="CC0 1.0" -metadata comment="Source: https://example.org/page" track.flac

    Search recipes

    Freesound API (CC0 loops and sounds). You need your own free API key from freesound.org. The API gives you previews to listen to; to get the original file, download it from the sound's page while signed in.
    curl "https://freesound.org/apiv2/search/text/?query=ambient+loop&filter=license:%22Creative%20Commons%200%22&fields=id,name,username,license,url,duration&page_size=30&token=YOUR_KEY"
    Openverse API (open audio from several sites; no key for light use, rate limited).
    curl "https://api.openverse.org/v1/audio/?q=ambient&license=cc0&page_size=20"

    Each result links to the original site: open that and do the six checks.

    Internet Archive command line. Install once, then search and read the item's details before downloading.
    pip install internetarchive
ia search "mediatype:audio AND licenseurl:*publicdomain/zero*" --itemlist
ia metadata ITEM_ID
ia download ITEM_ID --glob="*.flac"

    The licence address is written in different ways on different items, so also try licenseurl:*zero*. An item with no licence is not CC0.

    OpenGameArt (in the browser). Browse, choose Art type "Music" and License "CC0". Open each page, read the credits, then the text file in the download.
    Wikimedia Commons (in the browser). Search with the Audio filter, then read each file page's licensing box and author.
    ccMixter. It has a public query interface that accepts a licence filter. See its Query API page, and check each upload.

    If you work in Python

    The sound-slicing tools used for the Darklabs sound packs are command-line Python (numpy, scipy, soundfile). They find and score events in a recording; they do not download anything. They are private working tools, so the notes for them are kept with the project, not on this public page.

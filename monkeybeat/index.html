MonkeyBeat_

a browser drum machine made entirely of human monkey impressions

(browsers block audio until you interact — one click and it's live)

the default kit is sliced from real human monkey recordings

pattern — keys 1–8

sequencer — tap a step: full → medium → soft → off (right-click clears)

pads — keys A S D F G H J K

monkey keys — the selected pad, pitched up the scale

Octave 0

pad editor

export — WAV and MIDI for Reaper and game audio

MIDI in: off (notes 36–43 play pads 1–8)
how to use this thing
  • The eight pads start out as slices of one real monkey-impression recording. Swap any pad for another slice from the Library, or record new noises on your phone or mic and hit Load recording. Trim with Start / End, tune with Pitch. Your changes stay saved in this browser; Reset pad restores the default slice.
  • Monkey keys plays the selected pad up and down the scale, like MeowSynth. Turn on Keys mode to play it from the computer keyboard (A W S E D F T G Y H U J K O L P ; ', with Z / X for octave).
  • Tap steps in the sequencer to build a pattern. Each tap cycles the step's velocity. Patterns A–H can be chained in Song mode (type a chain like A A B A).
  • Press Rec while playing, then hit the pads (keys A S D F G H J K, on-screen, or MIDI). Hits are quantised to the nearest step.
  • Choke group makes pads cut each other off — put open and closed hats in the same group.
  • Bounce loop renders the pattern (or song) offline to a WAV. With seamless loop on, the reverb tail is folded onto the start so it loops cleanly in a game engine.
  • One-shot and Bundle export each pad dry (no reverb or filter), plus a manifest.csv for your tracking sheet. Files are named dre_[type]_[source]_v[NN].wav.
  • Pattern (.mid) exports MIDI with pads on notes 36–43, ready to drop into Reaper.

part of Dre Darklabs — built from human vocal recordings and run through the Web Audio API. no libraries, no build step, one page.
